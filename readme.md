# AI Interview Coaching System

An AI-powered interview preparation platform that analyzes CVs, extracts candidate skills, detects technical domain, and generates interview questions using NLP and LLM models.

---

## Features

- CV Parsing (PDF Resume Analysis)
- Skill Extraction using NLP
- Domain Detection (AI / Backend / Frontend / Data)
- Tech Stack Detection
- AI Interview Question Generation
- Interview Session Simulation
-

## Tech Stack

### Backend

- NLP
- Ollama (Phi3 LLM)

### Frontend

- React
- TailwindCSS

### AI / ML

- Skill extraction engine
- Domain detection system
- LLM-based question generator
